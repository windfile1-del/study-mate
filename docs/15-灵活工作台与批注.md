# 灵活工作台、课件批注和双模型识图（0.12）

保持当前冷白、青绿与玻璃质感的界面主题。左侧按“笔记 / 文档 / 课程”分类，各自提供导入、搜索和历史记录。笔记目录和库管理不再与课件、视频混排。

## 显示、隐藏与悬浮

顶部的侧栏按钮可完全隐藏或恢复资料导航，右侧工作台也有独立开关。点击悬浮按钮可将资料导航或伴学助手变成独立的小窗。拖动标题栏移动位置，拖动窗口边缘缩放，图钉控制置顶，“返回工作台侧栏”恢复停靠。窗口位置和置顶状态会保存，超出当前显示器时自动回到可见区域。关闭小窗不会退出主程序，顶部按钮可重新打开。

助手浮窗与停靠面板共享对话和输入草稿。隐藏右侧只收起界面；已打开的资料、笔记草稿和后台任务继续保留。

点击“让 AI 看本页 / 看原图”只显示简洁的提问和可移除的“参考来源”卡片。工具名称、内部资料 ID、读取页码的指令在发送时作为隐藏上下文附加，不写入输入框或用户消息气泡；你已经输入的问题会保留。资料仍按需读取，不预先发送全文或像素。浮窗与主窗口会一起保留这份来源引用。

## PPT 阅读与导航

打开 PPTX 后默认显示全部页面的缩略预览，滚动时按需生成，无需一次渲染整套课件。“目录与搜索”显示提取的每页标题，缺少标题时使用第一页非空文字；也可搜索可提取的内容和备注。点击页码、缩略图或目录项跳转。

在文档阅读区使用左右/上下方向键、PageUp/PageDown、Home/End。编辑输入框时不拦截方向键。PPT 默认开启滚轮翻页，可关闭；放大页面后优先滚动，到边缘才翻页。绘制批注时不滚轮翻页。PDF 保持常规滚动。

旧版二进制 PPT 当前只提取文字，不能提供真实页面缩略图或保真显示。PPTX 的动画、特殊字体和复杂效果仍可能与 Office 有差异。

## PDF/PPT 批注

阅读区工具条提供选择文字、手写笔、直线、荧光笔、颜色、橡皮擦、撤销、清除本页和保存。橡皮擦按整条笔迹擦除。笔迹按页保存，短暂停笔会自动保存，也可手动点击保存。

批注以归一化坐标叠加在页面上，窗口缩放后随页面显示。数据保存到应用数据目录下 `annotations`，与已注册文档的内容版本绑定。原始 PDF/PPT 不被改写；当前不是把批注嵌入原文件后导出。切换页码、重新打开软件可恢复批注。Markdown 不提供批注。

## 让视觉模型识图、文本模型推理

1. 打开“AI 接入设置”，上方接入你希望用于推理、问答、工具调用和写笔记的主模型。
2. 找到“图像识别专员”，勾选“启用视觉与文本双模型”。
3. 选择支持图片的服务，填写服务商提供的视觉模型 ID、接口地址和 API Key，保存图像识别设置。密钥留空时可复用同一服务已保存的密钥；也支持独立密钥。订阅方式需先在本应用完成对应服务授权。
4. 阅读课件时点“让 AI 看本页”，或提问让助手按需查看页面、图片、视频片段。不会因打开文档而自动产生模型费用。

启用后，图片像素只交给视觉专员。视觉专员只返回观察到的文字、公式、坐标、图形关系、来源和不确定性，不执行工具、不修改笔记。主模型收到文字观察及来源链接，继续推理和写作，因此可以选纯文本推理模型。关闭独立视觉模式时，沿用主模型直接看图的方式，主模型须支持图片。

视觉调用次数、模型与 tokens 单独显示，不混入主模型的缓存命中统计。工具定义保持固定顺序，历史协议数据保留；切换视觉分工属于协议边界，不复用带原始图片的旧请求前缀。实际缓存命中和费用仍取决于供应商返回与服务策略。

## OCR 的处理

未引入新的本地大模型。公式、函数曲线、图表和模糊板书默认直接使用多模态看原图。原有本地 OCR 仅保留在“识别与全库检索”折叠入口中，供清晰印刷文字兼容使用；低置信结果不应当作公式或图形理解的依据。

调研依据：[PaddleOCR 官方公式识别文档](https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/module_usage/formula_recognition.en.md) 的小型公式模型仍约 99–248 MB，且聚焦公式转写，不能覆盖函数图表语义；[LaTeX-OCR](https://github.com/lukas-blecher/LaTeX-OCR) 同样针对公式转 LaTeX，并引入额外推理环境。以上均不足以取代通用图表理解，因此没有增加模型体积。多模态识别仍可能误读，需要核对原图。

## 笔记来源超链接

系统提示词已要求助手：根据课件或课程写笔记时，在相关段落、公式旁主动插入实际读取证据的来源链接，而非仅在文末罗列。链接来自工具的真实 citation，禁止猜测文档 ID、页码和时间。

- 课件：`[课件名·第3页](study-cite://文档ID/3)`，点击返回对应课件第 3 页。
- 视频：`[课程名·01:25](study-video://来源ID/85)`，点击打开对应课程并定位到 85 秒。

这些链接由本应用解析，引用的文档/课程必须已在本应用注册。将 Markdown 单独复制到其他软件不意味着其他软件能识别本应用协议。模型是否遵循提示、识图准确率和真实供应商计费需用自己的账号验证；本地验收使用受控接口，验证实际像素、工具链、分流与跳转，不等同真实模型语义测评。
