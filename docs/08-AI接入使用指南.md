# 第一次连接 AI（0.7.0）

打开右侧伴学助手的设置按钮，进入“连接适合你的 AI”。登录账号和 API 密钥是两种接入方式，按已有服务选择。

## 使用 ChatGPT 订阅：SIWC

1. 选择“ChatGPT 订阅 · SIWC”，点击 **Continue with ChatGPT**。
2. 在浏览器的 OpenAI 官方页面登录，应用名称应为 **Study Mate**，确认同意使用套餐额度。不要在聊天框输入密码、验证码或令牌。
3. 回到工具，确认“已授权使用订阅”。“账号已验证，尚未授权套餐”只表示身份验证成功，不能调用套餐模型，可重新授权或改用 API。
4. 点击“获取模型列表”，选择账户返回的模型，先保留默认推理程度和上下文，保存设置。
5. 发送简短问题。收到完整回答才表示推理成功；登录和模型列表不代表具备全部模型权限。

应用按官方 SIWC 协议独立注册，保存服务端签发的应用 ID，不使用 Codex 登录身份、不启动 Codex、不读取旧版 Codex 凭据。升级后需重新授权。首次链接中的 dynamic_agent_client 是官方动态注册入口，并不是 Codex 客户端 ID，后续使用本应用获发的 ID。

“添加账户”保留其他独立授权，账户选择框切换当前授权。退出清除本地令牌并尝试远端撤销；未确认撤销时可到官方账号页面断开应用。资格、地区、组织、模型和额度由官方决定，不自动转向 API 余额。

参考：[官方 SIWC 登录](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)、[会话管理](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)、[模型与推理](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)。

## Antigravity：实验兼容接入

选择“Antigravity · 实验接入”，点击“使用 Google 账号登录”，在 Google 页面授权，回到工具获取模型、选择并保存。本应用重新授权，不导入 Harness-Mate 的账号令牌。

实现参考用户指定的 Harness-Mate：Google OAuth、项目发现、Cloud Code Assist 流和相同兼容标识。**这不是 Google 官方认可的第三方订阅入口，Gemini 会员不保证可用。** 官方条款第 6 条禁止第三方借用 Antigravity OAuth，并说明可能停用相关服务账户。[Antigravity 条款](https://www.antigravity.google/terms)

登录端口 51121 被占用时，请先完成或取消其他 Google 授权再试。失败不会自动改用付费 API 或读取其他软件登录信息。

## 使用 API 密钥

API Key 是识别调用和扣费的专用密钥，不是网页登录密码。

1. 选择 OpenAI、DeepSeek、通义千问、Claude、Gemini 或 OpenRouter。
2. 点击“打开密钥管理”，到服务商官方平台创建密钥，确认余额或配额。网页会员通常不等于 API 余额。
3. 粘贴 API Key 并保存。保存后不回显，留空保留原密钥。
4. 获取模型列表并选择、保存；失败时可手填服务商文档中的模型 ID。
5. 发送简短问题验证，列表不代表账户可用全部模型。

已有本地或兼容服务可选“自定义 / 本地兼容接口”，填基础地址、协议和模型。基础地址不要加 chat/completions 或 responses。本工具未内置本地大模型。本机允许 HTTP，网络服务要求 HTTPS。

## 参数与用量

对话栏模型卡片下方可直接切换已配置服务、模型和推理强度，无需再次打开接入设置。点刷新获取当前服务的模型列表；列表不可用时，点模型标签旁的“ID”手填并按 Enter。切换自动保存，下一次提问立即使用；正在生成的回答继续使用发出时的模型。不同模型的支持项以服务商为准，不确定时选择“由模型决定”。

- 模型：使用服务商提供的模型 ID，决定能力、速度与消耗。
- 推理程度：深入推理通常更慢且可能消耗更多额度。不确定时使用“由模型决定”，具体选项需模型支持。
- 上下文大小：包含历史、摘要、本轮问题和输出预留的本地预算，不能突破模型真实上限。
- 输出上限：单次生成预算，可能包含推理 tokens，过小可能导致不完整回答。
- 费用单价：高级设置按美元/百万 tokens 手填，未知留空；估算不含税费，不是账单。订阅不折算美元。

对话栏显示上下文占用，展开可看输入、输出、缓存命中/写入、推理与费用。未返回显示未知，不按零计算。本地估算带“≈”，与服务实际统计可能有差异。缓存命中是服务商报告的输入缓存量，不是本地缓存笔记数量。

## 按需读取、修改笔记与插图

勾选“笔记路径”后，首次只附加当前笔记路径和知识库标识。AI 可以调用工具搜索、列目录、按行读取相关内容；只有实际读取的片段才发送给所选服务商，不自动附上全文或整库。工具结果会进入当前对话上下文。

默认是只读模式。需要新建、替换、保存或插图时，勾选输入栏的“允许保存”，再说明修改要求。例如：“读取当前笔记，把第二节的错别字改正，保留其他内容并保存。”工具会先读取版本，再精确替换；冲突或存在未保存草稿时停止覆盖。现有文件的原文自动备份，成功保存后已打开的干净笔记自动刷新。

点击“学习工具”可查看实际执行状态，保存项提供“打开笔记”。工具执行失败不会被标为保存成功；停止后已保存的文件仍保留，不自动回滚或重放。

图片入口可选择本地文件，复制进当前知识库附件目录，原图不修改；路径放入尚未发送的问题。可接着要求：“把这些图片插入当前笔记第三节后并保存。”也可让 AI 查找库内图片、查看真实像素，再决定插入位置。支持知识库内图片和对话中视频工具返回的画面；没有模型图片生成或任意网络图片下载功能。

## 视频工具

先在本工具打开视频，再提问：“分析当前视频 0 到 20 秒的关键画面，写成笔记，并插入一张代表画面。”AI 可按需读取提问时冻结的字幕/进度，或对选中视频指定范围抽帧。每次最多 6 帧、最长 30 分钟采样范围；更长内容分段分析。

画面真实解码后才发送给所选模型，需要模型同时支持工具调用和视觉输入；仅支持文本的模型不能分析图片。切换视频后旧请求不跨源解析。抽帧不等于观看整段，当前没有音轨识别或自动语音转写。B站仍受当前网络、登录、站点权限及编码限制。

“课程字幕”仍可独立勾选，主动发送已冻结标题、进度、可见字幕与缺口；不勾选时，AI 也可按问题需要调用视频上下文工具。

## 缓存命中与上下文

输入栏展开用量后可查看本轮全部模型请求的累计输入、输出、缓存命中和加权命中率。工具调用会产生多次模型请求，统计不是只显示最后一次。上下文占用则按最后一次请求输入计算，避免误把累计输入当成单次上下文。

固定工具定义及顺序，静态系统说明置前，动态路径/权限放在本次问题尾部；后续仅追加历史。保留各协议的推理记录、签名与工具调用/结果，避免重写缓存前缀。Claude 开启官方自动缓存，其他服务按其接口自动缓存规则处理。模型、服务或账户切换、压缩、较短提示、首轮预热、TTL 到期都会影响实际命中。

不会填充无用文字抬高比例，也不会把未返回当作命中。真实缓存比例必须以服务商返回为准，未使用用户的真实额度测出固定百分比。参考：[OpenAI 缓存](https://developers.openai.com/api/docs/guides/prompt-caching)、[Claude 缓存](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)。

## 上下文压缩

积累足够轮次后可点“压缩上下文”。设置中默认开启自动压缩，接近预算 80% 时尝试，可调整比例。摘要使用当前模型，会额外消耗 tokens 或套餐额度。

压缩保留最近三轮完整问答，把较早历史合并为摘要，本次新问题不参与压缩。原始消息仍保存在本地，摘要与压缩前后估算可展开查看。只有完整生成且确实缩短上下文才提交；取消、断流或失败保留原上下文与原摘要。摘要可能遗漏细节，重要信息可重新明确。

单轮太长或压缩后仍超预算时提示调整或新建对话，不静默删除历史。“新建 AI 对话”归档旧消息与摘要到应用数据目录 ai/history。历史上限 2000 条消息或约 400 万字符，达到后需新建对话。

密钥错误检查密钥；订阅 401 重新授权；429 检查限流或额度；不完整回答可调整输出上限。中断不会自动重发产生费用。真实订阅授权、资格与计费推理尚未使用用户账号验收。
