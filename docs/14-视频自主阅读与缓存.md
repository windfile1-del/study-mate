# 视频自主阅读与后台缓存（0.10）

打开本地视频或在线课程，正常播放即可开始后台低清缓存，不必点“读取上下文”。在伴学对话框保留“自动看课”，直接问“刚才这一步为什么成立？”、“解释02:30到02:50的推导”或“先找到讲阻尼比的地方，再看原视频分析”。模型会收到发送时的课程ID、标题、进度和时间提示，按需选择工具读取证据。此时只有定位元数据进入初始问题，不把整课字幕或所有画面塞进上下文。

## 模型可以主动选择原视频片段

- read_video_frames：按时间读取后台低清缓存，每次最多6帧。
- read_video_subtitles：按原视频秒数读取已取得字幕，每次最多10分钟、100条、16000字。
- search_video_subtitles：用关键词查找字幕，再依据命中时间选择片段。
- watch_video：在后台打开原视频指定片段，最多120秒，概览6帧/细看12帧；模型可根据需要继续选下一片段或缩小范围细看。
- analyze_video：继续支持指定范围后台原片抽帧，每次最多6帧。已有read_transcript可以读取已产生的课程采音转写。

这不是仅把缓存照片交给模型。缓存不足时，模型可以直接请求原片；本地、可直接访问的在线媒体先用独立解码器读取。网页使用Blob/MSE等不能直接导出媒体地址时，会尝试另开不可见的独立网页，使用软件内当前会话，在该后台网页的播放器中读取所选时间。前台视频不被拖动、暂停或改倍速，后台页面静音。即使前台切课，模型仍使用发送时冻结的原课，网页需要重新加载时可能失败。

目前“观看”通过原片后台解码后的一组连续时间采样画面，结合按需读取的字幕/转写供视觉模型分析；不把原视频容器直接上传给模型，也不代表逐帧看到整段或听到了声音。快动作可以让模型缩小片段细看。无字幕课程若需要口头讲解，请先开启“课程语音”采音。实际视觉准确性取决于接入的模型，本功能仍需支持视觉与工具调用的模型。

登录、DRM、跨域内嵌、站点挑战、直播、无法独立加载的播放器和部分编码可能不支持后台读取。失败会保留错误与已有证据，不绕过权限，不伪造成功。B站沿用当前分P的真实cid及可访问流，字幕接口也使用软件当前登录会话；真实网络/账号权限决定能否取得。受控站点通过不等于真实站点全部可用。

## 字幕来源与时间

自动读取浏览器已经加载的TextTrack字幕轨（按原始cue时间），并补充B站已登录会话有权读取的字幕；只能看到页面字幕时会记录可见文本与估计的时间范围。本地视频会读取同目录、同名UTF-8 .srt/.vtt，或 .zh-CN/.zh 字幕，不改动文件。字幕有20000条容量边界。未加载或无权限的字幕会明确缺口。

字幕按提问时已取得的数据冻结；后续页面切换、跳转和新到字幕不会串入旧问题。模型可以根据字幕时间再读相应画面，回答引用实际来源时间链接。画面和原音/字幕是不同证据，不能仅凭字幕声称看过视频。

## 定时清理

左侧“识别与全库检索”→“视频缓存”：

- 默认启用自动缓存；约每2个原视频秒一帧，最高640×360 WebP，暂停不反复存相同位置；高倍速和页面状态可能形成间隔。
- 默认保留7天，所有课程低清缓存总预算512MB，每10分钟检查；可调整到1/3/7/30天、32MB至2GB、每1至60分钟。
- 超过时长先删，超过总空间从最旧画面淘汰；单课程还有2400帧/96MB上限。总预算是在启动及定时检查时收敛，检查间隔内可以暂时超过。
- 可关闭自动缓存，也可立即清理过期/超额缓存。设置保存后重启有效，面板显示最近检查的帧数、空间和释放结果。
- 清理只作用于应用数据目录中自动归档的preview画面。原视频、字幕、转写、知识库、手动/模型原片解析归档不在自动清理范围，后者仍可能占空间。

旧版本画面缓存保持可读。缓存被淘汰、跨域Canvas受限或没有播放过的范围会明确缺口，模型可按需后台查看原片。所有临时/数据默认在D盘，不要求另装FFmpeg、yt-dlp、Python或其他播放器。

## 用量与验证边界

本地缓存、字幕整理和定时清理不调用模型；只有发送问题后才产生模型请求，后台读取视频可能产生站点网络流量，视觉分析会消耗接入服务的额度。工具清单固定23项，动态定位只放本轮user尾部，历史像素、工具结果和原始协议记录保留，减少不必要的缓存前缀变化。供应商缓存命中不能保证固定比例。

原生验收包含中文VTT、真实HTTP/Blob视频、提问后切课、模型连续调用字幕/缓存/原片工具、前台控制写入计数不变，以及真实一分钟定时清理与重启设置恢复。模型工具选择由受控Provider驱动，用于验证真实执行与协议链；没有用用户真实账户验证模型语义、计费或服务端缓存率。
