# 0.6.0 学习工具与缓存

这轮实现固定十项本地学习工具及有边界的模型调用循环，不增加 shell、任意目录访问、浏览器控制、外部 MCP 或编码 harness。

| 工具 | 行为 |
| --- | --- |
| list_notes / search_notes | 目录分页、有限范围搜索 |
| read_note | 最多200行、16000字符，返回版本/行数/下一行；长行明确截断 |
| save_note | 新建或完整保存；覆盖前要求完整读取 |
| replace_in_note | 精确字符串替换，默认不允许多处匹配 |
| list_images / view_image | 图片路径分页及按需真实像素输入，最长边1280 |
| insert_image | 插入库内图片或对话已返回画面并保存，使用相对 Markdown 链接 |
| get_video_context | 提问时冻结的进度、字幕、最多3张已有画面及缺口 |
| analyze_video | 同一选中视频的指定范围原生抽帧，1至6帧/最多30分钟范围 |

实现：core/study-tools 复用 VaultService；core/ai-wire 负责跨协议历史映射；ai-providers 流式解析工具调用；main/ai-service 串行执行/预算/取消/持久化；MediaController 新桥接复用原解码队列和 TaskManager。原 AgentRuntime 测试接口保留，不与产品工具循环混用。

默认只读，允许保存作为本次请求权限冻结。路径始终局限授权知识库，先读版本再写；整篇覆盖要求完整行范围，局部修改用精确替换，失败不猜版本。未保存草稿与外部编辑冲突拒绝覆盖；原文通过 VaultService 自动备份。工具调用ID在单轮去重，磁盘 operationId 保留现有幂等保护，不在重启后自动重放。最多12个模型步骤/24次工具调用，达到预算明确停止。停止不回滚已提交文件。

图片入口由用户原生选择，复制到附件目录，原图不改；模型不获得任意本机路径读取权限。视频工具返回真实像素和 frame:ID，不含音轨转写；不声称看完视频。像素需要视觉模型，纯文本模型可能拒绝。B站真实网络限制继续单独报告。

## 缓存设计

- 静态系统说明、固定工具列表/顺序复用；读写模式、知识库标识和路径放当前用户消息尾部，不动态重写系统前缀。
- 保存首次发送的 user.prompt，后续严格追加，避免过去的路径/字幕被重新格式化。
- Responses 保留 output 项与 encrypted reasoning，Chat 保留 tool_calls/reasoning_content，Claude 保留 thinking/signature/tool_use，Gemini/Antigravity 保留所有 parts/thoughtSignature 及原函数ID，续接不伪造签名。
- Claude 使用官方自动 cache_control，其他服务保留其自动缓存行为。不填充虚假长前缀、不捏造缓存命中，也不为了命中忽略权限或继续使用旧文件版本。
- 模型/服务/账户隔离原生历史；跨模型用可读历史回退，不把其他模型的 opaque 签名发过去。
- 累计本轮每次请求的输入/输出/缓存量，按 sum(cached)/sum(input) 算加权命中；最后请求输入单独计算上下文占用。未返回字段保持未知。
- 真实缓存取决于服务端、长度门槛、TTL、模型/账户/推理配置和压缩。替身给出的75%只用于统计校验，不代表真实模型验收。压缩是必要时主动改变历史前缀，不每次工具调用都压缩。

原始 native、签名与画面存于 main 的聊天记录，界面轮询只返回文本和工具活动摘要。压缩保留原消息，只对早期历史提交摘要。包含像素的长对话会增加本地存储，达到预算需压缩或归档；没有承诺无限历史。

## 验证

62项自动测试：文件边界、只读/草稿/版本/备份/幂等、全篇覆盖读取门槛、CRLF多行精确替换、图片复制、工具像素、多工具结果顺序，以及四种协议与Antigravity的原始签名重放、续接和缓存前缀一致性。

workspace-ai-smoke 使用受控 HTTP 模型响应触发真实执行链：列目录、搜索、读取、替换、原生视频抽帧、插图、新笔记保存、干净编辑器刷新；还验证图片导入、连续九次请求及下一用户轮的前缀/工具清单完全相同，累计缓存用量准确。真实解码与文件落盘执行，但语义回答由替身提供。

真实 API/SIWC/Antigravity 账户的工具权限、视觉推理和服务端缓存命中率未使用用户额度验收。结果以 artifacts/workspace-ai-packed 和 artifacts/standalone/result.json 为准，不能把本地测试数字当作真实服务指标。
