# 0.14 · 逐篇恢复与紧凑伴学界面

## 恢复一篇笔记

左侧打开“资料与备份管理 → 笔记备份”，先在左列选择笔记，再在右列选择某个时间版本。支持预览和“恢复此版本”，只改变该篇笔记，不恢复整个知识库。相同文件名会显示所在目录。清理勾选版本也只作用于当前选择的备份记录。

恢复前会备份当前内容。未保存草稿和磁盘版本冲突会阻止覆盖；旧版哈希备份如果没有原路径，会单独列在“旧版 · 待确认归属”，需要明确指定恢复目标。

## 模型核对与回退

模型保存已有笔记后，保存结果会返回修改前的 `backup_id` 和 `previous_version`。系统提示要求用 `read_note` 按行核对改动，发现误改时调用 `restore_note_backup` 回退同一篇笔记。

恢复工具需要本轮允许保存、已经读取的当前版本和明确归属于这篇笔记的备份。不能用 A 的备份覆盖 B，不能越过未保存草稿或外部编辑。恢复前也会备份错误版本，方便再次核对。新建笔记没有修改前备份时不会声称已回滚。

工具提供恢复能力；模型是否判断出语义错误仍取决于模型和证据，本轮受控测试不等于真实模型能发现所有错误。

## 紧凑输入栏

模型和思考程度放在输入栏右下角。模型列表支持搜索、切换已接入服务、刷新，以及折叠的手动模型 ID 入口。思考程度用紧凑滑条与可点击刻度显示。模型卡宽约 248 CSS 像素，思考卡宽约 216 CSS 像素，长说明放在悬浮提示内；菜单不会超出窗口。

附近的竖向进度条表示上下文窗口占用，悬浮或键盘聚焦时显示已用、剩余和总容量，也可手动压缩。服务没有返回实际输入指标时明确标为估算。累计 tokens 放在输入框下方，点击可查看主模型、视觉、压缩及缓存详情。

## 并排与拖动

右侧打开笔记、视频或课件时，优先保留输入栏、发送按钮和累计用量。顶部资料区会限制高度；消息列表独立滚动。小窗口、图片引用和错误提示不会把发送区域推到屏幕外。浮窗也沿用相同紧凑布局。

分隔条拖动时按动画帧直接预览 CSS 尺寸，松手才提交工作台状态与布局保存；Esc 取消，方向键继续支持调整。拖动过程中暂停原生视频区域的重复布局及课件重复栅格化，结束后同步最终尺寸。没有改动用户的主样式表。

## 本轮验证

只运行受影响的恢复权限、工具协议、压缩提示、分组备份、模型控件、上下文、并排布局与拖动检查，不重跑无关的登录、ASR、OCR和全库性能测试。成功检查与依赖指纹保存在 `artifacts/0.14`。`npm run test:refinement` 和 `npm run smoke:refinement` 会复用未变化的成功记录。
