# PDF 与 PowerPoint 阅读和理解

2026-10-26 · 0.8.0-documents

用户已验收此前实现，本轮在原有方案 T34/T35 上增加 PDF 与 PowerPoint 阅读、按页理解和可定位来源，不重做已验收功能。

## 使用方法

1. 左侧点击「打开 PDF / PowerPoint」，选择 PDF、PPTX 或旧版 PPT。文件保留原样，应用在 D 盘数据目录创建内容快照，文件移动后历史引用仍可使用。
2. 顶部可以翻页、输入页码、缩放或恢复适合宽度；目录按钮展开目录和文字搜索。PDF 使用文件内目录，PPTX 使用幻灯片标题；没有目录时仍可跳页。搜索每次最多20页，可继续搜索。
3. PDF 可直接选择文字；右侧「文字/框选」按钮切换图表框选。幻灯片可以框选图像，也可展开下方「本页文字与识别说明」「演讲者备注」选择文字。
4. 对话框勾选「文档·第N页」，输入问题。首次仅附文档编号、版本、页码与主动选区，不自动发送整份文件。AI 按需读取相关页；分析图表需要具备视觉能力的模型。
5. 答案中的页面来源可以点击跳转。保存到 Markdown 的同类链接在本应用中也能打开；其他编辑器不一定认识 `study-cite://`。
6. 拖动文档标签到右侧，或点击标题右侧「文档移至另一侧」，即可并排查看文档、笔记或视频，AI 对话随之缩小。拖动分隔条调整比例。

导入的文档保存在应用数据目录 `documents/files`；目录和最后阅读页保存在 `documents/library.json`。内容哈希确定快照身份；同一内容复用，改过的文件重新导入后生成新快照，旧引用保持指向旧内容。此版本不提供文档编辑、批注写回或自动删除快照。

## 格式支持

| 格式 | 阅读与理解 | 边界 |
| --- | --- | --- |
| PDF | PDF.js 静态页面、文本层、目录、文字选择、页面或选区图像 | 扫描页明确显示文字缺失；可交给视觉模型，不自动 OCR。加密文件由用户在阅读器输入密码，密码只保留运行内存，不发送模型或持久化 |
| PPTX | Canvas 静态幻灯片、文字/表格提取、演讲者备注、页码搜索、视觉理解 | 字体以本机可用字体替代；复杂公式、SmartArt、动画、嵌入音视频与 Office 可能不同，不能当作完整 PowerPoint 播放器 |
| PPT | 本地解析复合二进制中的幻灯片文字，简化分页阅读与文字理解 | 原版式、图片、复杂旧字符集不保证；不提供原始页面图像，建议使用 PPTX/PDF。加密或无法提取的旧文件报错，不伪造页面 |

阅读引擎随软件打包，不需要额外安装 Office、LibreOffice、Node.js、Python、FFmpeg 或转换工具，不上传在线预览。首次打开需复制文件到 D 盘；大文档请预留空间。PDF/PPTX 最大128MiB，旧 PPT 最大32MiB；PPTX 压缩资源另有总160MiB/单资源40MiB/10000项预算；页面栅格最多800万像素，超过时请降低缩放。损坏文件会报错。

## 架构与上下文缓存

- `core/document-registry.ts` 管理用户选择文件后的授权、不可变快照与元数据；renderer 和模型不能传任意磁盘路径。
- `main/documents.ts` 通过随机令牌协议提供单个快照，协议只注册在可信默认会话，远程课程浏览器没有处理器。文件解析、文字提取和画布渲染在独立隐藏 renderer 内完成；不提供 Node、远程导航或弹窗权限。
- PDF.js Worker、CMap、标准字体、WASM 都是包内文件。PPTX 禁止自动请求 Google Fonts；引擎 CSP 也不允许远程连接。文档中的宏、JavaScript、外部网页和附件不作为程序执行。
- 单页按需渲染，界面切页采用去抖与过期结果丢弃；引擎最多保留3份文档，输出缓存最多24页/估算32MiB。淘汰后可从快照恢复。工具取消会终止解析窗口，下一次重新加载；单次解析60秒上限。
- 固定14个学习工具：原10个加 `list_documents`、`search_document`、`read_document_page`、`view_document_page`。工具列表不随选中文档或写权限变化。文字工具单页最多16000字符正文/8000字符备注，搜索最多30页；扫描缺口、截断和 PPT 静态限制明确返回。
- 发送瞬间冻结文档ID/修订/页码/选区及已授权文档列表，不在工具执行时临时读取前台标签。图像仅在显式工具调用后进入模型，可通过既有 `insert_image` 保存到知识库附件。
- 系统提示和工具定义保持稳定，动态文档元数据只附本次用户消息尾部；历史原始工具、图像、推理与签名沿用现有持久化。供应商实际缓存命中依赖其规则与上下文，不把受控测试数字当作真实命中率保证。

## 验证与限制

单元测试验证快照不可变、重启引用、授权范围、二进制 PPT Unicode 文字、ZIP 预算、工具页码冻结与按需图像。原生 Electron 受控场景验证 PDF 真 Worker/画布、扫描页、局部裁剪、搜索、PPTX 中文/表格/备注和实际颜色像素、旧 PPT 文字、分栏、对话按页工具及来源跳转。模型端使用本机受控 Provider，未消耗真实订阅额度，不能代替真实模型语义质量验收。

已用 PDF.js 官方 issue3371 密码样例验证错误密码拒绝、正确解锁显示与重启后重新要求输入密码，密码不写入元数据。复杂密码/权限组合、生产大课件、全部 Office/旧 PPT 兼容性仍需实际文件补充覆盖。当前不包含全书索引、OCR、ASR、动画播放或文档编辑。

参考：[PDF.js](https://mozilla.github.io/pdf.js/examples/)、[pptx-browser](https://github.com/bowespublishing/pptx-browser)、[JS-CFB](https://github.com/SheetJS/js-cfb)。依赖许可与三处固定版本适配见 `vendor/documents/NOTICE.md`。

开发验证中，密码样例首次下载到 D 盘 `.cache/fixtures/password-issue3371.pdf`，记录内容哈希；来源为 https://github.com/mozilla/pdf.js/blob/master/test/pdfs/issue3371.pdf，仅用于本地回归，不随产品分发。运行应用阅读本地文档不需要该下载。
