# 0.2.0 内置视频解析

用户目标：解压一个软件即可完成笔记、视频播放与画面解析，不安装或配置外部运行工具。此阶段不包含语音转录、AI回答和PDF。

## 数据路径

本地文件选择或已授权最近来源 → SourceRegistry版本身份 → MediaController冻结目标 → TaskManager → 独立Chromium解码窗口 → MediaStore归档 → 解析结果与LearningService上下文。

B站视频在解码前增加：BV+分P → view接口pages中的真实cid → playurl → 选择H.264 DASH视频流 → MediaGateway会话代理。p不是cid。

普通网页只接受视频currentSrc中与课程同源的http(s)媒体地址；Blob/MSE不作为可重放直链。B站通过平台接口解析MSE背后的可访问流。拒绝用户名/密码URL，B站视频主机限定HTTPS CDN域名，重定向重新校验。

## 进程与权限

- 主界面：sandbox preload窄API，所有IPC校验主frame与精确来源URL，输入由Zod限制。
- 远程课程：独立持久化browser会话，没有文件与解码API，不注册study-media处理器。前台preload只读观察。
- 本地播放器：独立会话，只载入随包player.html与令牌媒体资源，没有shell API。
- 解码器：独立离屏BrowserWindow，Node关闭、sandbox/contextIsolation/webSecurity开启，不展示、不连接Agent、不控制前台。
- MediaGateway：主进程将用户选中的单个文件或校验过的网络视频映射为随机令牌；本地流支持HEAD、单Range、后缀Range、206/416；网络请求继承课程会话，签名媒体URL不落盘，不读取/导出Cookie。
- 解码令牌任务结束即撤销；本地播放令牌关闭或切换课程时撤销。取消任务销毁解码窗口并传递AbortSignal。

使用Electron/Chromium自带媒体运行库。包内ffmpeg.dll为Electron附带组件；没有ffmpeg.exe、ffprobe.exe、yt-dlp.exe子进程调用或系统PATH依赖。

实现参考：[Electron协议](https://www.electronjs.org/docs/latest/api/protocol)、[会话fetch](https://www.electronjs.org/docs/latest/api/session)、[MDN视频帧回调](https://developer.mozilla.org/en-US/docs/Web/API/HTMLVideoElement/requestVideoFrameCallback)；平台字段对照开源[yt-dlp B站提取器源码](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/bilibili.py)，未安装或调用该工具。

## 解码合约

请求提交时冻结来源，排队后不重新获取当前课程。单任务抽取1–12帧，界面提供3/6/9/12帧。范围为秒，终点为空表示片尾，超出时长裁剪，起点大于终点明确拒绝。输出最高1920×1080且不放大源视频，返回真实宽高、时长、解码帧媒体时间。

定位既等待seeked，也等待目标mediaTime附近的视频帧回调，忽略旧画面的延迟回调；画面索引/帧率无法满足精确定位则明确失败。避免精确片尾无法解码的位置。不能用海报、旧帧或目标时间冒充实际解码证据。

加载/定位有25秒超时，解码窗口整体有180秒上限。解码队列串行，应用任务系统保持可取消；不阻塞主界面。D盘归档包含WebP与不含图像字节的manifest；重启从最近完整结果加载画面。

LearningService按冻结来源、最近90秒与证据截止时间合并已有原生帧和观察预览，最多6帧。解析结束后取得的画面不会回填到更早冻结的请求里。

## 笔记修复

新增多文件Markdown导入，同名自动追加编号、保留原件； UTF-8/BOM/CRLF验证；每文件2MiB、每次32个。部分失败列出原因并保留成功结果。导入知识库内文件直接打开，不重复复制。相对图片与附件不随导入迁移。

选择已有知识库不限盘符。所有暂存和备份在D盘：同卷提交rename/link；跨卷EXDEV使用复制，原内容事先备份。跨卷替换不具备rename原子性；本轮只模拟EXDEV验证，不创建C盘测试临时目录。

Explorer打开当前知识库、定位当前笔记均通过主进程校验。原生模态框期间暂时隐藏课程原生视图，finally恢复原期望可见性；取消选择与返回保存不会让视频消失。

## 验收分层

- 核心：27项检查，覆盖导入、版本冲突、范围、来源、任务和媒体证据截止。
- 原生：真实本地MP4、HTTP Range网络视频、受控B站分P接口、画面定位、前台控制写入为0、取消与重启；文件选择和Explorer使用自动化替身。
- 独立包：直接运行随包exe，PATH只包含Windows系统目录，重复媒体链路。验证其运行依赖包含在软件内。
- 真实B站：独立未登录profile，当前网络出错页/ERR_BLOCKED_BY_CLIENT；额外公开view接口请求HTTP412。此层尚未成功，不能由受控接口替代。
- 未验收：用户实际点击原生选择器/Explorer、其他盘符物理保存、登录账号/会员清晰度、所有编码、长时间运行、大规模缓存、签名/自动更新。

测试样片来自[MDN CC0 flower.mp4](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4)，只供本地验收，不随产品打包。
