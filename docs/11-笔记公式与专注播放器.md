# 0.7.0：笔记公式、快捷模型与专注播放器

## 修复笔记

用户指定的《多元函数微分学与二重积分讲义》《二阶过阻尼系统动态指标与闭环主导极点估算例题》包含 `$$公式` 开头、后续行以 `公式$$` 收尾的块。原 remark-math 流式数学围栏不能把带内容的末行作为结束围栏，会把后面的正文、Callout、标题一直吞到另一个独立 $$，造成整段红色源码。

math-source.normalizeDisplayMath 在渲染入口将这种独占段落的混排定界符分成独立行，支持普通/缩进列表及引用容器，跳过代码围栏/行内代码及原始HTML代码区。规范化不写回 Markdown，幂等；worker首屏切分与最终排版使用相同输入，AI回答也使用同一兼容入口。KaTeX版本/CJK分式支撑、代码包装及sanitize流程保留。

只读审计结果：第一篇1195块/167节，第二篇48块/12节，公式错误均为0。桌面验收使用副本，原始和副本均比较前后字节。仍不能承诺全部MathJax扩展或所有损坏的Markdown均兼容。

## 对话栏快捷切换

模型卡片下方可选已配置服务、模型及推理；刷新仅请求目录，“ID”可手填未知模型。select请求原子更新并保存后续配置，不关闭聊天，不要求重走登录；当前生成/工具循环继续使用发送时快照。只改变模型/推理时保留目录，跨服务/账户时清理相关目录，revision防止慢查询覆盖新选择。

可在当前回答生成中切换，用于下一次提问。上下文/输出预算受服务返回的模型窗口约束，模型不支持的推理选项应保留auto。更换模型/账户仍隔离原始签名，不伪造缓存命中。

## 纯视频与播放控制

课程浏览器及右侧视频区提供“开启纯视频”。主进程通过受限 browser:player 接口操作同一个网页video节点，不重新加载媒体，不迁移播放会话：隐藏网页内容及DOM弹幕，视频铺满区域，可选字幕置于画面下方。宿主工具条负责播放、暂停、进度、倍速、字幕开关。

优先选择可见面积最大的video，支持普通HTML视频、可访问的同源内嵌与开放shadow root。记录并恢复修改过的样式、controls及字幕轨模式。切换模式不主动播放或定位；播放失败说明网页交互限制。直播/未取得时长禁用进度定位。仅切换已有字幕轨或已加载的B站字幕容器，不能生成缺失字幕、移除烧录文字或规避跨域/DRM/站点限制。

远程页面无contextBridge权限；控制命令仅可信主窗口可发，严格校验数值和动作，不向AI工具开放。观察preload继续只读。IPC纯函数与原生视图沿用现有分栏隐藏/边界计算。
