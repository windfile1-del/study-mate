# Study Mate 架构与开发方案

调研日期：2026-10-25（Asia/Shanghai）。修订：r2，笔记优先复用开源组件，首个可用版本目标7–12人日。实现状态：已建立0.1.0-core基础工程；详细进度见 [开发日志](开发日志.md)，设计条目不等于已实现能力。

首版范围已经用户确认：Windows 桌面端，支持 B站、本地视频、PDF、Markdown 笔记库和 AI 问答。

## 推荐路线

使用 Electron + React + TypeScript 建立学习工作台，从现有视频观察插件提取观察能力，配合独立 Agent Runtime、本地 Markdown Vault 和轻量学习索引。应用内部通过受控 IPC 通信，MCP 保留为后续的外部接入方式。

笔记直接集成 @uiw/react-md-editor、react-arborist、chokidar 等组件，补充本地文件和AI工具接口；首版约1–2人日完成笔记集成。视频沿用现有模块和文件归档，SQLite/FTS属于后续数据增长时的演进方案，不要求首次交付前全面改写存储。

先完成“边看课程 → 询问刚才内容 → 有来源的解释 → 保存并继续编辑笔记”的闭环，再增加完整语音转录、OCR、语义检索和更多网站。Alpha 的字幕/画面模式与 Beta 的音视频模式分别验收。

现有插件继续独立使用；新应用迁移其模块与测试，不依赖 Codex 桌面端，不要求安装 Obsidian，也能直接打开已有 Markdown 知识库。
