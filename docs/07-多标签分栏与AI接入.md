# 0.4.0：笔记工作区与 AI 接入

> 历史实现：0.5.0 已移除 Codex 运行库接入并改用 SIWC；笔记仅附路径，新增压缩和 Antigravity 实验接入。当前架构见 [0.5.0](09-SIWC与上下文压缩.md)，操作见 [AI 指南](08-AI接入使用指南.md)。

本轮范围：修复公式排版；多标签与历史导航；可拖动的三栏工作区；内置 Codex 订阅运行库；主流 API 接入、对话与用量显示。PDF、ASR/OCR、Obsidian 插件执行不在本轮范围。

## 笔记与布局

- `renderer/workspace/note-desk.ts` 是独立状态模型。主工作区与右侧学习区各有标签列表、激活位置和最多 100 条导航历史。正文草稿按路径共享，跨区移动不会丢失未保存内容。
- `useNoteDesk` 承担按需读取、请求代次、版本检查保存、冲突副本、关闭确认和滚动位置。切标签不会自动覆盖磁盘；退出/切库前检查全部草稿。并发保存使用同步集合保护。
- `NotePane` 复用现有 Markdown 编辑器与 Worker 预览，两个区域不会共享滚动容器。Alt+左/右返回和前进，Ctrl+Tab 切换标签，Ctrl+W 关闭，Ctrl+S 保存当前区域笔记。
- 左、右宽度与右侧上下高度可通过 Pointer Capture 拖动，也可聚焦分隔条后用方向键调整；布局偏好保存在本地。主区保留最小可用宽度，窗口过窄时限制极值。
- 笔记和视频标签可拖入右区或移回，也有明确的按钮入口。右区展示学习内容时，AI 收为小输出区和输入栏。视频仍使用同一个 WebContentsView，变更位置和边界，不重新打开来源。拖动、调整和模态窗口期间隐藏原生视图，防止遮挡控件。

## 公式修复

原先 `rehype-katex` 使用 KaTeX 0.16.47，根样式却来自 0.19.1，内部类名不匹配导致分式/连乘重叠。根依赖固定为 0.16.47，使笔记和 AI Markdown 的排版引擎与字体样式一致。Mermaid 自带依赖不替换。

针对用户补充的中文分子/分母过密问题，在解析出的数学节点内调整显示：行内中文分式采用 displaystyle，中文分式参数增加零宽度 rule，确保正常字号和上下高度；长公式横向查看。不修改原始 Markdown，不处理代码围栏中的 LaTeX。保留 remark-math 已生成的 code 包装结构；不能直接替换块公式的全部 hChildren，否则会退回代码显示。

## AI 分层

| 层 | 实现与职责 |
| --- | --- |
| shared/ai | 配置与请求 Zod 校验、消息/用量类型、服务商预设与新手说明 |
| core/ai-providers | Responses、Chat Completions、Anthropic Messages、Gemini generateContent 的请求映射、SSE 流、用量归一化与上下文预算 |
| main/ai-service | 加密密钥、配置、对话归档、按次读取选中的笔记/冻结字幕、取消和生命周期 |
| main/codex-client | 官方 Codex app-server 的 stdio JSON-RPC、登录、模型目录、推理、通知、取消与异常退出 |
| preload / IPC | 仅受信任的主窗口可调用 ai:request；远程课程页没有此能力 |
| renderer/ai | 服务商向导、账号登录、参数表单、流式对话、资料选择、用量与费用明细 |

预设 OpenAI API、DeepSeek、通义千问/百炼、Anthropic Claude、Google Gemini、OpenRouter、自定义兼容服务，以及 ChatGPT/Codex 官方订阅。API 基础地址与协议可修改；密钥保留在主进程，通过 Electron safeStorage/Windows 加密，系统加密不可用时拒绝明文保存。仅本机地址允许 HTTP，网络接口要求 HTTPS，不跟随重定向，密钥放请求头。

所有 API 默认推理由模型决定。用户可调整程度，需服务商/具体模型支持；Codex 从内置版本对应的学习目录读取推理程度。Anthropic 使用 adaptive thinking + effort，Gemini 使用 thinkingLevel，DeepSeek 使用 thinking toggle + reasoning_effort。Codex 目录随应用内置版本更新，未知模型拒绝进入编码工具 fallback；模型列表是目录，不是权限或额度验收；请求成功完成才证明该次模型可用。旧模型不支持某项参数时会明确失败，不静默切模型或切换付费方式。

## Codex 官方订阅

随包携带未修改的官方 Windows x64 Codex 0.164.0，用户无需额外安装 CLI、Node 或 Python。只打包问答所需的主可执行文件；版权与 Apache-2.0 文本随包提供。

独立 CODEX_HOME 位于 `<应用数据>/ai/codex`，工作目录和临时目录也位于 D 盘。通过 `account/login/start` 的 chatgpt / chatgptDeviceCode 模式交给官方流程处理登录和续期；系统浏览器打开受信任的官方域名，设备码作为备用方式。强制 `cli_auth_credentials_store=keyring`，不读取用户原 Codex auth.json，不采用明文 fallback，不继承终端中的 API Key。系统凭据库不可用时需修复系统凭据功能，不能降级为明文令牌。

初始化使用应用身份 `study_mate`；读取 account/model，再创建 ephemeral thread。每次发送包含预算内的文字历史；生成成功必须收到 completed，失败/中断不能记为成功。订阅模式绝不自动转 API 计费。

本轮固定的 0.164.0 协议实际生成 schema 中，`thread/start.sandbox` 是 `read-only`，`turn/start.sandboxPolicy.type` 是 `readOnly`；不能混用在线文档中的另一版本枚举。使用同版本官方 models.json 派生的学习目录，移除 apply_patch、shell、code mode 和额外工具元数据，并关闭本地图像查看、exec、JS REPL、apps、multi-agent、web search 与权限申请；不能仅依赖已成为兼容空操作的 apply_patch_freeform 开关。实际官方运行库向本地 Responses 替身发起推理时，已断言请求 tools 数组为空。客户端另外拒绝所有服务端工具/审批请求，检测到工具执行条目时中断。不会给模型开放知识库写入或播放器控制。

## 上下文与统计

- 只有点击发送时才发送问题、预算内文字历史和勾选的资料。笔记读取已保存版本；字幕读取已冻结的课程标题、进度、字幕和缺口。不发送整库、视频文件或画面。对话资料不会被当作应用授权。
- 上下文大小是本地预算，不能扩大模型本身上限。预留回答空间和协议开销，超过预算时移除较早的完整问答并在用量明细提示；当前问题或资料本身过大则拒绝发送。
- API 输出上限映射原生参数；Codex 的输出预留仅影响本地预算，不能伪称已强制限制官方服务的生成上限。
- 输入、输出、总量、推理、缓存读取和写入优先采用服务商的返回值。Anthropic input_tokens 不包含缓存读取/写入，归一化时相加；Gemini 思考用量单列。未返回是 null，UI 显示“未返回”，不填 0。
- 占用比例优先使用服务商本轮返回用量，无数据时显示本地估算。缓存 token 数与费用不是本地缓存大小。
- 可填写美元/百万 token 的输入、缓存读取、输出单价；缺必要统计或存在未知缓存写入价格时费用保持未知。估算不等于账单。Codex 显示“套餐额度”，不虚构美元金额。
- 流被截断、额度/鉴权错误、输出上限和取消保留已收到内容，并区分状态。新建对话把旧内容归档至 ai/history 后再清空；当前会话最多 120 条消息/约 200 万字符。启动时把未完成消息标为中断，不重放请求。

## 验证及边界

自动测试覆盖四种 API 的本地 HTTP/SSE、跨包 UTF-8、缺失用量、累计用量、费用估算、截断/取消/401、预算与配置校验；Codex 以 JSON-RPC 替身覆盖登录通知、流、用量、失败和取消，另用真正的内置程序验证初始化、独立未登录账号、模型目录、只读线程创建及对本地 Responses 替身的完整推理和零工具请求。新窗口测试使用真实指针拖动、Markdown/KaTeX、草稿/历史、长文位置恢复、双向视频分栏、加密存储及 UI 截图。

真实 API 余额扣费、真实 Codex 账号登录后的推理、组织策略/地区和套餐额度未使用用户账号验收，不能以本地替身或模型目录代替。视频真实站点的既有网络限制仍然存在。具体运行结果见 artifacts 下 result.json 与开发日志。
