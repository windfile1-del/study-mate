Study Mate 0.10.0 · Windows x64

解压整个压缩包，双击 Study Mate.exe 即可使用。请保留 exe 同目录的资源文件与 DLL。
运行时不需要安装 Node.js、Python、FFmpeg 或 yt-dlp。
媒体解码使用应用附带的 Electron/Chromium 运行库，ffmpeg.dll 属于其内置组件，无需安装或配置。

首次运行使用 D:\StudyMateData 保存应用状态、默认笔记、浏览器会话、临时文件与备份。
知识库可以通过左侧“切换知识库”选择其他盘符上的 Markdown 目录。
项目原来的笔记在 D:\study-mate\.local\data\vault；可选择该文件夹继续使用。
在工程目录双击“启动工作台.cmd”，会优先运行打包版本并继续使用工程原来的数据目录。

笔记：支持 UTF-8 Markdown 导入，同名自动创建副本，导入不会复制相对图片或附件。
左侧文件夹图标打开当前知识库，编辑器文件夹图标定位当前笔记。
Obsidian 常用语法：行内/块级LaTeX公式、Mermaid图表、双链别名/标题/块引用、图片尺寸、Callout、YAML属性、脚注、表格、高亮和笔记嵌入。
阅读模式只渲染可见内容，长文首屏优先，后台排版可取消，最近笔记缓存；目录可以直达章节，长流程图可以滚动和放大。
公式使用KaTeX，不能保证全部MathJax扩展命令兼容；不执行Obsidian插件/Dataview查询，不支持Excalidraw直接编辑。
笔记嵌入最多一层，跨笔记公式编号/引用和完整Obsidian工作区布局尚未兼容。
视频：支持内置播放、指定秒数范围、3/6/9/12帧后台解析；解析结果保存在应用数据目录。
B站：按分P查询实际cid并读取可访问的H.264视频流；可能受到登录、站点限制和编码影响。
不支持受保护内容、直播及所有MSE/Blob来源的独立解析；可继续使用已观察的课程上下文。
AI：点击右侧设置，接入主流 API、ChatGPT 订阅 SIWC 或 Antigravity 实验兼容。SIWC 以 Study Mate 独立授权，不启动 Codex、不读取旧登录；升级需重新授权。
支持模型、推理程度、上下文预算、流式回答、停止生成、token/缓存统计；美元费用需填写单价后估算，套餐不换算美元。
对话栏可直接切换已配置服务、模型与推理强度；刷新列表或点“ID”手填。自动保存并用于下一次提问，当前回答继续用原模型。
浏览器上方点击“开启纯视频”，隐藏网页评论/弹幕，只保留视频与可选字幕；可播放/暂停、拖动进度、调整0.5至4倍速度和切换已有字幕。“恢复原网页”还原网页布局及原生控制栏。
跨域内嵌、封闭播放器及站点限制可能不支持；字幕开关只作用于已有可控制字幕，不能移除烧录在画面中的文字或弹幕。课程语音可手动开启采音，不绕过站点授权。
密钥/令牌由 Windows 加密保存。模型列表不代表推理权限，套餐资格和额度以服务商为准，不自动转向付费 API。Antigravity 参考 Harness-Mate，非官方第三方接入，有服务账户停用风险；Gemini 会员不保证可用。
勾选笔记先发送路径与知识库标识，AI 按需搜索、按行读取相关片段。默认只读，开启“允许保存”后可新建、精确替换、完整保存和插图；原文自动备份，冲突或未保存草稿不覆盖。工具执行记录可展开，保存项可打开笔记。
“图片”入口可将选中的本地图片复制到知识库，原图不改。可让 AI 插入库内图片，或把视频抽帧插入笔记。没有任意文件系统/命令行工具，也不下载任意网络图片。
打开视频后可让 AI 分析指定范围，工具每次抽取1至6张真实画面，采样范围最多30分钟；需要支持工具和视觉的模型。用户开启采音后，可按需读取已产生的转写；不声称完整观看视频。课程上下文冻结在提问时，切换视频后不跨源解析。
工具定义/顺序与历史前缀保持稳定，保留推理签名及工具结果，Claude 启用自动缓存。用量累计本轮所有模型请求，显示实际返回的加权缓存命中率；缓存由服务商控制，首轮、短提示、压缩或过期可能不命中，不能保证固定百分比。
支持手动和自动上下文压缩，保留最近三轮及本次问题，较早历史生成摘要；原消息留在本地。成功且缩短后才提交，失败/取消保留原摘要。压缩会额外消耗当前模型 tokens 或套餐额度。
真实 API 计费和真实订阅授权/推理未使用用户账号验收。
左侧“识别与全库检索”：中文课程采音、原图理解、可选OCR、全库全文/语义/反向链接检索。模型全部随包，无需额外工具或手动下载；AI看图需连接视觉模型。

这是本地开发构建，尚未进行代码签名与自动升级配置。
开源组件许可见同目录许可证及resources内的notices文件。

视频自主阅读（0.10）：正常播放时约每2秒自动保存最高640×360画面，提问不需先点“读取上下文”。对话框“自动看课”启用后，发送课程ID、冻结进度和时间定位提示，模型按需读字幕/缓存或主动选择原视频片段后台观看。网页Blob/MSE会尝试独立后台页面，前台不被暂停、跳转或改变倍速。原片连续采样不是逐帧完整观看，声音需已有课程采音转写；DRM、跨域内嵌、登录和站点限制可能失败。模型只分析实际取得的证据，不伪造成功。
字幕支持已加载TextTrack、B站有权访问的字幕、可见DOM及本地同名UTF-8 SRT/VTT，按时间或关键词定位，回答来源可点回原时间。原图/视频像素按需进入模型，不自动塞入整课缓存或全文字幕。
左侧“识别与全库检索”→“视频缓存”：默认保留7天、总预算512MB、每10分钟清理；可调整或立即清理过期/超额帧。单课程2400帧/96MB。仅清理自动低清帧，原视频、字幕、转写、笔记与原片解析归档保留。详细限制见“视频阅读与缓存说明.md”。

多标签：Ctrl+Tab 切换、Ctrl+W 关闭、Ctrl+S 保存、Alt+左/右 返回与前进。
拖动三处边界可调整目录/工作区/右侧区域，视频或笔记标签可拖到右侧并排查看，AI 自动缩为小窗。
退出旧版后再启动新版；工程启动脚本沿用 .local/data。新版独立 exe 默认使用 D:\StudyMateData。

文档阅读：左侧“打开 PDF / PowerPoint”。PDF 支持页码、缩放、目录搜索、文字和图表选区；PPTX 支持静态预览和演讲者备注，旧 PPT 仅简化文字。无需安装 Office 或转换工具。文档标签可移到右侧并排查看。提问勾选“文档·第N页”，AI 只附页码和主动选区，按需读取文字或图像，回答来源可点回页面；原文件不修改，D盘保留快照。可直接“让 AI 看本页”或选区，OCR为可选参考。复杂字体/公式/动画可能与Office不同。详见随包“文档阅读说明.md”和“中文采音与多模态检索说明.md”。

中文采音默认只采当前课程标签音轨，不录麦克风或其他软件；请先开启并等待连接完成，再播放课程。倍速、暂停和跳转会分段映射到原视频进度；点击时间可核对原音。术语和噪声会造成误识别，识别结果保留提示和对齐缺口。
复杂、模糊、手写和公式以视觉模型查看原图为主，无需先跑OCR；OCR评分不是正确率。点击原图入口后需检查问题并发送，图像在工具调用时按需交给模型。
切换知识库后后台建立持久化全文索引；全库检索不受目录树5000篇展示上限和旧500篇/64KB限制。语义索引手动开启，可暂停，显示覆盖率；反向链接支持常用双链和别名。单篇2MiB、UTF-8，索引变化可能短暂滞后，不承诺十万级恒定速度。
