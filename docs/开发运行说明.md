# Study Mate

Windows 本地学习工作台。当前为 **0.10.0-video**。新增约2秒一次的低清视频后台缓存、时间/字幕定位、模型主动选择原片在后台观看，以及缓存定时清理；保留中文采音、原图理解、全库检索、PDF/PPTX、多标签和 AI 接入。

## 启动

普通使用：退出旧版，解压 release/0.10.0/Study-Mate-0.10.0-Windows-x64.zip 的完整内容，双击 Study Mate.exe；也可直接运行 release/0.10.0/win-unpacked/Study Mate.exe。保留同目录资源，无需安装 Node.js、Python、FFmpeg 或 yt-dlp，旧版本保留。

工程内双击“启动工作台.cmd”，优先运行独立包并继续使用 .local/data 中已有的数据。直接双击包内 exe 时，默认数据目录为 D:\StudyMateData；首次运行可通过“切换知识库”选择原来的 D:\study-mate\.local\data\vault。所有缓存、备份、浏览器 profile 和临时文件保存在 D 盘。

以下命令仅供开发使用。建议 Node.js 24，当前依赖安装要求 Node.js 22.12 或更新版本。

首次安装：

~~~powershell
cd D:\study-mate
.\scripts\install.ps1
~~~

开发模式：

~~~powershell
npm run dev
~~~

运行构建版本：

~~~powershell
npm run build
npm start
~~~

开发入口为“启动开发.cmd”。npm run dist 构建 Windows x64 独立运行目录与 ZIP 包。

开发数据默认保存在 D:\study-mate\.local\data；可用进程环境变量 STUDYMATE_DATA_DIR 指定其他 D 盘目录。通过上述命令启动时，临时目录、npm 缓存和 Electron 下载缓存均显式放在项目的 .cache 下。

## 当前可以使用

- 多笔记同时打开、每区域独立返回/前进、保留标签草稿与长文滚动位置。
- 拖动目录/工作区/右侧之间的分隔条调整宽度；拖动视频或笔记标签到右侧并排查看，AI 自动收为小窗口。
- 中文分子/分母使用可读字号和上下间距；普通连乘/分式不再因 KaTeX 样式版本混用而重叠。

- 新建、打开、搜索和保存普通 UTF-8 Markdown 笔记，现成编辑器支持源码/预览。
- 导入外部 UTF-8 Markdown 文件，同名自动创建副本，不改动原件；图片和附件不随导入复制。
- 选择任意盘符上的现有 Markdown 知识库，监听外部新增/修改/删除；打开知识库目录或定位当前笔记。
- 渲染行内/块公式、Mermaid图表、双链别名/标题/块引用、相对/双链图片、Callout、属性、脚注、高亮、表格和一层笔记嵌入。
- 阅读/分栏/源码模式、章节目录、长图滚动和放大。大文档在Web Worker排版，首屏优先显示，预览只挂载可见块，快速切换可取消旧排版。
- 保存时检查版本，保留备份；发现外部修改时保留编辑器草稿，可另存副本。
- 打开含 HTML 视频的网页。观察器只读取进度、低清画面和可见字幕，不调用播放器控制API。
- 按请求冻结来源和进度，查询最近约90秒的本地画面/字幕；切网页后仍查询原请求。
- 内置播放本地视频，支持情况取决于 Chromium 解码器，优先使用 MP4/H.264 或 WebM。
- 独立后台解码本地视频、同源直接媒体地址，以及 B站可访问的 H.264 流；指定秒数范围抽取3/6/9/12帧，最高1920×1080，不放大原片。
- 解析结果归档并在重启后恢复，当前进度附近的已解析画面可进入学习上下文。
- 任务排队、取消、错误状态与重启后的 interrupted 状态。

AI：点击右侧设置，接入主流 API、ChatGPT 订阅 SIWC 或 Antigravity 实验兼容。支持参数、流式回答、取消、笔记路径/课程字幕、用量明细和手动/自动压缩。SIWC 以 Study Mate 独立注册，不使用 Codex 登录或运行库；Antigravity 非官方且有账户风险，不保证会员额度可用。

首次接入与工具操作见 [AI 使用指南](docs/08-AI接入使用指南.md)，当前实现见 [学习工具与缓存](docs/10-学习工具与缓存.md)。默认只读，开启“允许保存”后可修改/插图，原文自动备份。“图片”入口导入本地图片；视频分析需支持工具和视觉的模型。未使用用户账号验收真实订阅、工具/视觉推理或服务端缓存命中率。PDF/PPTX 已接通按页文字和图像工具；使用方法见 [文档阅读指南](docs/12-PDF与PowerPoint阅读.md)。中文采音转写、可选 OCR、全库持久化/语义/反向链接检索已接通，见 [中文采音与多模态检索](docs/13-中文采音与多模态检索.md)。任意文件/命令行工具和自动升级不在当前范围。

前台观察使用 Canvas；原生解析使用独立离屏 Chromium 窗口，不拖动前台播放器。Electron 自带的 ffmpeg.dll 属于随包运行库，不调用 FFmpeg/yt-dlp 命令行程序。直播、DRM、部分编码及不能解析的 Blob/MSE 来源会明确失败。

B站解析按 BV+分P查询真实cid，然后读取当前会话有权访问的视频流。受控接口已验证全链路；本机未登录真实站点测试遇到错误页/ERR_BLOCKED_BY_CLIENT，另外的接口请求返回HTTP412，真实站点成功解析尚未验收。

跨盘笔记保存使用D盘暂存与备份再复制提交，无法提供同卷rename级别的原子替换；已通过模拟EXDEV分支测试，未写入C盘测试文件。

~~~powershell
npm run check
npm test

npm run smoke

npm run smoke:chinese

node scripts/workspace.mjs smoke-standalone
node scripts/workspace.mjs smoke-media-dev
npm run dist

~~~

78 项自动测试覆盖原有核心与工具、混排公式边界、播放参数、持久化大库检索与音轨时间映射。新功能与边界见 [笔记与播放器](docs/11-笔记公式与专注播放器.md) 和 [中文采音与多模态检索](docs/13-中文采音与多模态检索.md)。中文样本可用 scripts/prepare-chinese-fixtures.ps1 准备，模糊课件测试通过 STUDYMATE_CHINESE_BOARD 指定现有图片；测试复制原图，不写回原件。原笔记回归仍使用指定原笔记的副本及受控模型/视频网页，不修改原知识库。

笔记压力验收在artifacts/notes-smoke和artifacts/notes-packed：1204篇知识库、2200节公式长文、目录/图片/嵌入/快速切换。真实知识库样本仅做只读验证，并比较前后字节。KaTeX不能覆盖全部MathJax扩展；本应用不运行Obsidian第三方插件，任务列表和属性当前以阅读为主。

原生验收使用独立D盘profile和本地受控视频页面，不访问个人知识库或模型账户。结果与截图分别在 artifacts/core-smoke 和 artifacts/core-smoke-dev。关闭保护的自动化场景模拟用户选择“返回保存”；未宣称自动化点击了真实原生对话框按钮。

媒体验收见 artifacts/media-smoke、artifacts/media-dev 和 artifacts/media-packed，使用MDN CC0 MP4样片，含真实解码、HTTP Range、受控B站分P解析、取消与重启恢复。原生文件选择和系统Explorer操作在自动化中使用返回值/调用替身，真实文件读写、窗口、播放器与解码执行。独立包验收时PATH仅保留Windows系统目录。首次运行媒体验收若无样片缓存，会从MDN下载约1.1MB的CC0样片；产品运行不需要下载此样片。

## 代码入口

| 目录/文件 | 职责 |
| --- | --- |
| apps/desktop/src/main | Electron生命周期、窗口/网页视图、IPC授权、AppKernel |
| apps/desktop/src/preload | 可信界面窄API；远程页面只读观察，不导出特权API |
| apps/desktop/src/core | 来源、任务、笔记、学习上下文、Agent与工具 |
| apps/desktop/src/shared/contracts.ts | 运行时校验、IPC和业务类型 |
| apps/desktop/src/renderer | React工作台及开源编辑器/目录树集成 |
| vendor/video-observer | 用户原插件src的项目内副本及变更来源记录 |
| tests | 面向数据安全、隔离和任务语义的回归 |
| docs/开发日志.md | 本轮实际完成内容、验证证据与未测边界 |

原有视频观察插件目录未被修改。应用不依赖Codex桌面端运行，也不会使用原插件的缓存目录。

工作区与 AI 最新验收见 artifacts/workspace-ai 和 artifacts/workspace-ai-packed，含真实指针操作、视频分栏、草稿/历史、加密、路径不含正文、压缩及流取消。node scripts/workspace.mjs smoke-standalone 将独立包复制到工程外，同时验收笔记、媒体和 AI/分栏，汇总见 artifacts/standalone/result.json。

视频自主读取与缓存定时清理见 [视频阅读指南](docs/14-视频自主阅读与缓存.md)。固定23个学习工具，缓存与字幕按需读取；模型可主动调用watch_video选择原片片段。后台缓存不产生模型费用，主动观看以实际采样画面和字幕为证据。
