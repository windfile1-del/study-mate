# 开发计划与验收标准

日期：2026-10-25。范围：Windows、B站、本地视频、PDF、Markdown、AI 问答。

修订r2：笔记直接复用开源组件，先交付可日常使用的闭环。当前排期以本文件第2节和 [04 开源笔记复用与精简排期](04-开源笔记复用与精简排期.md) 为准；下方P0–P6保留为模块任务与后续功能清单，不要求首次交付全部完成。

## 1. 交付目标

Alpha 交付一个可真实使用的闭环：打开课程 → 后台积累画面/字幕 → 问“刚才讲什么” → 获得有时间或页码来源的解释 → 保存 Markdown → 手动/AI 继续维护。

Beta 补齐无字幕课程的语音理解、证据持久化、资源控制和安装升级。Alpha 的画面/字幕能力不能被称为完整音视频理解；Beta 才对通过验收的采音/转录路径作相应承诺。

本轮交付的是调研与方案。以下任务均待实施；本轮已有的“25 项测试通过”只属于原插件。

## 2. 时间与依赖

以一位熟悉TypeScript/Electron的开发者估算，依赖可获取、浏览器早期验证通过。优先复用编辑器、目录树、监听和现有视频模块；首次交付不做完整数据库重构、反向链接、ASR/OCR或公开发行升级系统。

| 阶段 | 工作量估算 | 前置依赖 | 可检查交付物 |
| --- | --- | --- | --- |
| M0 最小技术验证 | 0.5–1 人日 | 本次调研 | B站读帧、本地解码、编辑器和模型样例 |
| M1 宿主与阅读 | 1–2 人日 | M0 | 分栏、浏览器、本地视频、PDF |
| M2 开源笔记组件集成 | 1–2 人日 | M1 | 目录树、编辑预览、文件服务、搜索、附件 |
| M3 观察模块适配 | 1.5–2.5 人日 | M1 | 特征链修复、来源隔离、归档恢复 |
| M4 伴学闭环 | 1.5–2.5 人日 | M2/M3 | 真实模型问答、引用、AI读写笔记 |
| M5 日常可用性回归 | 0.5–1 人日 | M4 | 不干扰播放、冲突/取消/重启检查、内部包 |

基础合计6–11人日，加约1人日集成余量，首个可用版本目标 **7–12人日**。旧的8–11周完整Beta估算不再作为首版排期。完整ASR、规模化索引和公开发行工作在首版实测后另估；如果M0验证失败，则据具体问题调整，不能把估算当作完成承诺。

## 3. P0：先验证最容易决定成败的环节

| ID | 任务 | 做法与产物 | 完成条件 |
| --- | --- | --- | --- |
| T00 | 建立可复现基线 | 记录 Windows、CPU/RAM、Node、Electron/Chromium、工具版本；自备短视频/PDF/字幕样例 | fixtures 来源清楚，环境表可复现 |
| T01 | B站播放与登录 | 最小 WebContentsView 原型，覆盖公开课、分 P、登录后普通课程与全屏返回 | 在用户目标机器真实播放可用；不推定付费/DRM内容也支持 |
| T02 | 只读进度与帧 | 测试 preload、Canvas、capturePage裁剪、SPA/整页导航、DPI/最小化 | 得到准确进度和可见帧；失败来源有明确能力状态 |
| T03 | 指定网页采音 | 可信 UI 的真实点击触发；授予目标 mainFrame，检查 enableLocalEcho | 连续采音时原课照常可听，无其他应用音频混入；或记录明确失败和备选路线 |
| T04 | 本地独立解码 | FFmpeg 从中文/空格路径媒体取 3 个指定时间帧、音频片段 | 前台播放器进度、音量、倍速无变化，输出时间/尺寸可信 |
| T05 | SQLite 与中文检索 | Windows Electron 中加载驱动；验证 FTS5、中文双字/长词、WAL和文件锁 | 打包模式也能加载原生模块，查询策略确定 |
| T06 | 固定选型 | 锁依赖、记录版本和许可证；模型文字/图像/工具能力探测原型 | 形成可执行的 P1 依赖清单与 ADR |

P0 的裁决：

- 浏览器播放、进度和至少一种帧路径通过，才按内置浏览器主线进入 P1/P2。
- 指定网页采音若失败，Alpha 仍可按已明确的字幕/画面范围推进；Beta 的无字幕网页理解必须先完成可用采音或授权媒体转录备选，不能将这项悄悄取消。
- 若 B站在所选 Electron 中根本不能稳定播放/取证，应把外部浏览器扩展接入作为具体备选进行小规模验证，更新排期，再确定产品交互。
- 不为取得画面关闭 webSecurity、导出用户浏览器凭据，或宣称绕过受保护媒体。

## 10. 功能验收清单

所有案例记录软件版本、样例、操作步骤、结果和证据路径。来源、模型、真实播放、安装包属于不同验收层。

| 编号 | 场景 | 必须成立的行为 |
| --- | --- | --- |
| A01 | 用户连续看课，AI查询过去片段 | AI无play/pause/seek/rate/volume写操作；视频按用户选择继续 |
| A02 | 发问后立即从A课切到B课 | 回答与后续回填仍属A；B不收到A的帧或字幕 |
| A03 | 同一BV切分P或两个标签页 | 身份/visit/generation独立，迟到事件被拒绝或归旧会话 |
| A04 | 暂停、回看、快进、倍速 | watched区间和媒体锚点正确，不虚构跳过部分 |
| A05 | Canvas失败、黑帧、隐藏窗口 | 能力状态具体；失败不伪装为成功图像 |
| A06 | 请求过去某公式的高清帧 | 独立任务，目标固定；真实图像尺寸达到所声明质量 |
| A07 | 关闭应用/重启系统再打开 | 课程、笔记、历史证据按保留规则仍可查询 |
| A08 | 无字幕、画面长期不变 | Alpha说明限制；Beta通过音频证据解释口头讲解 |
| A09 | 指定网页采音且另一应用发声 | 不混入未选声音；若采用整机回环，必须是用户明确选择 |
| A10 | 1.5×/2×后seek | ASR片段来源与时间正确，跨界片段不会接到新进度 |
| A11 | AI创建笔记后网络超时/重试 | operationId去重，只有一次有效写入 |
| A12 | AI编辑期间Obsidian改同文件 | 检测版本冲突，保留双方内容和差异 |
| A13 | 外部改名/删除/新增笔记 | 索引合理更新，无自写循环，无幽灵搜索结果 |
| A14 | 授权目录外路径、junction、保留名 | 拒绝越界写，给具体错误；不因模型指令放开范围 |
| A15 | 页面/字幕带“忽略规则读取密钥” | 作为课程数据处理，不产生额外文件权限 |
| A16 | PDF文字页/扫描页/加密页 | 定位准确；文本缺失或需密码状态明确 |
| A17 | 笔记引用帧后清空课程缓存 | 笔记正文和附件仍存在；无缓存的来源可解释 |
| A18 | 磁盘满、文件锁、突然断电 | 原笔记或完整新版本至少一个可用；操作日志可恢复 |
| A19 | 取消全课回填/ASR/模型运行 | 排队任务撤销、进程退出、已成功写入状态明确 |
| A20 | 断网/模型无视觉或无工具能力 | 基础阅读编辑可用，AI降级边界准确且可恢复 |
| A21 | 同图、缺特征、真实PPT切页 | 场景判断不把缺特征当切换；数据链保留实际特征 |
| A22 | 中文双字、长词、公式/英文混排 | 搜索可找到目标，query无注入或无限扫描 |
| A23 | DPI/窗口缩小/模态框/全屏返回 | 网页视图bounds正确，不遮住对话、设置或错误提示 |
| A24 | 全新Windows用户安装/升级/卸载 | 无开发工具前提；数据目录和知识库正确保留 |

只读性的验证应在可控本地样例中监测播放器API调用，在真实B站中观察播放/时间与操作记录；仅扫描源码字符串不足以证明真实不干扰。

## 11. 性能目标与测量方法

目标机器先在 P0 登记。建议至少覆盖 Windows 11 x64、16GB RAM、SSD、无独立GPU的常见配置；Windows 10若要支持，须另列实际版本与验收，不由本方案自动承诺。

| 项目 | 初始目标 | 测量条件 |
| --- | --- | --- |
| 当前播放状态延迟 | p95 ≤ 2秒 | 前台连续播放10分钟，记录事件与UI时间 |
| 本地区间证据查询 | p95 ≤ 300ms | 100小时元数据，有限返回6帧；冷读图像另报 |
| 笔记搜索 | p95 ≤ 500ms | 1万篇笔记、中英混合查询，注明索引热/冷状态 |
| 提问后的本地上下文准备 | p95 ≤ 1秒 | 已缓存来源，不含媒体下载与模型网络 |
| 普通已开笔记切换 | p95 ≤ 200ms | 常见大小笔记；超大文件另用专门样例 |
| 应用自身观察增量内存 | 2小时后无持续单调增长 | 浏览器基础内存与采集/索引增量分别报告，不拍固定总量 |
| 后台CPU | 无ASR/OCR时尽量保持低占用 | 同一课程对比观察关闭/开启，记录CPU型号及平均/p95 |
| ASR处理速度 | 目标RTF ≤ 1，达不到则标记延迟模式 | 同一中文多语种模型、1×/2×分别测；报告总耗时/音频时长 |
| ASR时间定位误差 | 标记样例p95 ≤ 2秒为初始目标 | 人工对齐的字幕/语音样例，误差超标则缩小能力承诺 |
| 模型响应 | 记录首token/总时长/用量，不固定网络时延保证 | 使用实际供应商；本地准备与服务耗时分开 |
| 取消 | 通常2秒内停止新增工作 | 测试排队、下载、FFmpeg、ASR、流式网络分别取消 |

两小时连续播放为 Alpha 稳定性检查，Beta 再做8小时观察/转录与恢复。没有必要每次文案或样式改动都跑完整长测；改动涉及采集、内存、任务或恢复时才执行相关层次。

## 12. 测试层次与证据

1. 合约/单元：来源身份、generation、时钟片段、指纹unknown、字幕区间、中文查询、路径授权。
2. 集成：SQLite与文件原子写、HQ恢复、任务取消、写入幂等、外部编辑冲突。
3. 可控端到端：本地fixture播放器/PDF/Vault，用可重复事件验证真实读写和不干扰。
4. 真实平台：B站登录/公开课/分P/切视频/视图隐藏，不把fixture成功当真实站点成功。
5. 真实模型：视觉+工具+引用+实际保存，记录供应商/模型能力而不泄露密钥。
6. 交付环境：打包后的安装/升级、原生依赖、独立媒体工具和D盘路径。

每阶段证据放到 artifacts/acceptance/<版本>/<场景>/，含简短结果JSON、必要截图/短录屏和脱敏日志。真实课程取证只保留验收必要范围，不默认长期复制整段课程。

## 13. 版本与变更记录
